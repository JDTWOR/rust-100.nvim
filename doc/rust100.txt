*rust100.nvim*  Study the 100 Exercises to Learn Rust course from Neovim.

Requirements ~

Neovim 0.10+, Git, Rust/Cargo, the course repository, and `wr` (workshop-runner).
`rust-analyzer` is recommended for Rust completion and diagnostics.

Setup ~

    require("rust100").setup({
      course_root = vim.fn.expand("~/src/100-exercises-to-learn-rust"),
    })

If `course_root` is omitted, rust100 searches upward from the current buffer
and working directory for the course structure.

Commands ~

                                                        *:Rust100*
:Rust100                  Open the course dashboard.
:Rust100 open [index]     Open an exercise and its Markdown lesson.
:Rust100 lesson [index]   Open the lesson for an exercise.
:Rust100 check            Register and check the current exercise with `wr`.
:Rust100 next             Open the next exercise.
:Rust100 todos            Put TODO and todo!() markers in quickfix.
:Rust100 health           Show required tools and course detection.

The optional index is one-based and follows `book/src/SUMMARY.md`.

Dashboard keys ~

    j / k       Select an exercise
    Enter       Open the selected exercise and lesson
    l           Read the selected lesson
    r           Verify the selected exercise
    ?           Show dashboard key help
    q / Esc     Close the dashboard

Progress ~

rust100 stores its current exercise and completed checks in Neovim's state
directory under `rust100/`. Checks also update the course runner's official
`exercises/progress.db`. The dashboard does not read that private SQLite
schema, so work done directly through `wr` does not automatically update its
local checkmarks.
